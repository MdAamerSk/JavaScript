# JavaScript Essentials: Fundamentals & Logic Practice

A comprehensive repository dedicated to mastering the core fundamentals of JavaScript. This project contains a collection of practical exercises covering everything from basic syntax, variables, and data types to advanced conditional logic and multi-step algorithmic problem-solving.

## 🚀 Overview

The codebase (`script.js`) serves as a practical playground implementing essential JavaScript features across 10 distinct concept categories. It showcases clean code practices, variable manipulation, type coercion quirks, and control flow mechanics.

---

## 🛠️ Concepts Covered & Features

### 1. Console Mechanics & Basics
* Standard logging, tabular data tracking (`console.table`), warning assertions (`console.warn`), and error simulations.

### 2. Variables & Memory Basics
* Working with block-scoped (`let`, `const`) vs function-scoped (`var`) identifiers.
* Memory swapping algorithms using temporary containers.

### 3. Data Types & Type Mutations
* Implementations of primitive types: `String`, `Number`, `Boolean`, `Null`, `Undefined`, and `BigInt` handling.
* Implicit type coercion vs explicit casting methods (`Number()`, `String()`, `parseInt()`).

### 4. Mathematical Operations & Built-ins
* Arithmetic, exponents, and remainder structures.
* High-precision operations using the native `Math` object (`Math.random()`, `Math.floor()`, `Math.sqrt()`, `Math.max()`).

### 5. String Architecture
* Inspection and text mutation methods (`.slice()`, `.replace()`, `.trim()`, `.split()`, `.repeat()`).
* Dynamic interpolation utilizing ES6 Template Literals.

### 6. Control Flow & Evaluation Logic
* Multi-branch conditionals (`if-else if-else`) and discrete evaluation switches (`switch-case`).
* Verification algorithms (Leap Year calculators, complex grading scales, and traffic simulation systems).
* Evaluation of Truthy vs Falsy structures in JavaScript.

### 7. Logical Thinking & Micro-Apps
* Real-world mathematical implementations:
  * Celsius to Fahrenheit conversion formulas.
  * Simple Interest and customized percentage assessment engines.
  * Variable-rate utility bill calculation algorithms.
  * Secure credential validation checks.

### 8. Challenge Implementations
* Dynamic 4-digit OTP generation sequences.
* Manual sequence reversing algorithms.
* Multi-subject automated marksheets compiling raw scores, custom percentages, and alphabetic letter grades.
